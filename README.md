# Digital Hunter

A landing page I designed for a made-up mobile and XR game development studio called Digital Hunters. Built to practice a dark, tech-forward brand style, not a real company.

## About

The idea was to design something that feels like a real game studio's site — a big hero section with a sci-fi character, stat counters (years of experience, downloads, team size), and a projects showcase carousel featuring a few fictional games.

## Built with

- HTML
- CSS

No frameworks, just plain HTML and CSS.

## Features

- Full-width hero section with a sci-fi character image and bold typography
- Stat counters row (years of experience, projects completed, downloads, team size)
- "Our Projects" carousel with arrow navigation and project cards
- Platform icons (Android/Apple) on each project card
- Footer with contact info and social icons
- Bilingual sections (Russian text mixed with English) for extra styling variety
